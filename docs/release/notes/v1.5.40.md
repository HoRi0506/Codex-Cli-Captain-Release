# v1.5.40

- adds conditional `diagnose_then_fix` decomposition with a first-class `compare_gate`, so inspect-then-fix requests only open `raider` mutation work when evidence shows a mismatch
- protects read-only, design, analysis, and "do not mutate" requests from being over-classified as mutation work
- recovers mutation-required `codex exec` runs that changed files but missed the terminal result contract as file-change-only completion and routes them to verifier review instead of terminal failure
- persists delegation worker result envelopes to `delegations/<delegation-id>.result.json` sidecars for independent result recovery
- adds session route journal `worker_heartbeat` and `latest_heartbeat` visibility, and attaches `execution_continuity` to bounded `foreman_orchestrate` timeout acknowledgements
- adds `codex-foreman maintain-runs --action <archive|prune>` as a dry-run-first retention maintenance surface with guarded `--apply`
- refreshes the Korean route reference for the current fresh-run-first, `compare_gate`, heartbeat, and file-change-only recovery behavior
- rewrites the source README and generated release-repo README into a compact install/use/status/run-hygiene oriented style
- updates install-facing docs for the `v1.5.40` GitHub Release tarball

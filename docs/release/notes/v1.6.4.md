# v1.6.4

- adds the low-cost `scribe` documenter role and routes docs-only mutation away from `raider`
- keeps implementation mutation on `raider` and review on a single default `arbiter`
- adds per-agent `fast_mode`; enabled workers launch with `service_tier=fast`
- fixes `repair_action=retry` so repair goes back to the correct worker instead of a generic operator hold
- separates `captain_synthesis_allowed` from `host_mutation_allowed`
- updates `$cap` so host Codex must not perform direct git/filesystem mutation while Foreman owns the run unless the operator explicitly approves a bypass
- keeps git read on `companion_reader` and git mutation on `companion_operator`
- records delegated worker process ids so status can show process-aware lifecycle state instead of relying only on repeated status polling
- lets `drain_until_boundary` consume bounded verifier `needs_work` repair automatically when retry budget remains
- updates README and install docs for the 1.6.4 install path and phase-chain behavior
